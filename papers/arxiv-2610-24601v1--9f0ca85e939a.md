###### Abstract

Traditional Chinese medicine (TCM) research connects classical texts,
medicinal entities, molecular assays, computational predictions, and
clinical studies. An autonomous research agent must preserve the
inferential boundaries between these evidence types while coordinating
analysis across heterogeneous resources. We introduce TCMScience, a
scientific knowledge-discovery agent that separates language-model
proposals from execution and release authority. Its architecture
combines a trusted kernel, a scientific compiler, and claim-support
contracts: plans are compiled into typed operations, execution is
bounded by explicit permissions, and candidate findings are checked
against source provenance, study design, and claim scope before release.
The full capability registry contains 117 public-source connectors with
444 typed operations across 29 domains and 150 native tools across 12
domains; the TCM data hub catalogs 136 databases, 76 dataset
specifications, and 84,294 formula-source records. These resources
support model-independent workflows through browser and local execution
interfaces. In a network-pharmacology analysis of Gegen Qinlian Tang,
replacing the whole-proteome background with the assayed-protein
background changed the number of significant pathways from 66 to zero;
incorporating inactive screening records identified nine pathways,
including drug-metabolism signals retained as mechanistic hypotheses. A
governance ablation over 121 constructed erroneous outputs spanning 26
classes released 121 errors without governance, 57 with the domain
layer, seven with the kernel, and zero with both layers. All 10
compliant controls were retained. These results establish complementary
control of known failure modes and show how explicit evidence contracts
change the conclusions an agent is permitted to report.

## 1 Introduction

Scientific knowledge discovery in traditional Chinese medicine (TCM)
requires reasoning across sources that answer different questions. A
classical passage establishes what a text records; a
chemical-composition resource associates a constituent with a medicinal
source; a binding assay measures an interaction under a specified
protocol; a molecular model predicts a structural or functional
property; and a clinical study estimates an outcome in a defined
population. Combining these records does not erase the conditions under
which each was produced. The central challenge is therefore to compose
useful research workflows without converting evidence from one domain
into a stronger claim in another.

Existing TCM artificial-intelligence research provides essential
components of this workflow. Machine-learning systems analyze diagnostic
modalities\[[1](#bib.bib1)\]; knowledge graphs organize herbs, formulas,
syndromes, diseases, and their relations\[[2](#bib.bib2)\]; and domain
language models, including ZhongJingGPT and HuatuoGPT, support medical
dialogue and reasoning \[[3](#bib.bib3), [4](#bib.bib4)\]. Graph-based
retrieval systems such as OpenTCM connect these structured resources to
natural-language interaction\[[5](#bib.bib5)\]. These advances make
relevant knowledge more accessible, while leaving the validity of a
composed scientific inference as a distinct problem.

Scientific agents extend language models from answering questions to
acting on them. Coscientist and ChemCrow combine planning with chemical
tools\[[6](#bib.bib6), [7](#bib.bib7)\]; The AI Scientist and
Co-Scientist develop research and hypothesis-generation workflows
\[[8](#bib.bib8), [9](#bib.bib9)\]; and Biomni coordinates biomedical
tools, data, and executable analysis\[[10](#bib.bib10)\]. As these
capabilities expand, a technically successful tool call and a
scientifically supported conclusion must remain separate objects.
Correct execution of a docking program does not establish a therapeutic
effect. Accurate retrieval of a paper does not authorize extending its
result to an unstudied population.

Network pharmacology makes this distinction particularly consequential.
It links formula constituents, targets, and pathways to generate
mechanistic hypotheses\[[11](#bib.bib11), [12](#bib.bib12)\], but
enrichment depends on the sampled proteins, annotation density, inactive
records, and multiple-testing procedure\[[13](#bib.bib13),
[14](#bib.bib14), [15](#bib.bib15)\]. A research agent can produce a
fluent mechanism narrative even when the apparent signal is attributable
to the assay background. The failure occurs at the boundary between
computation and interpretation, where additional retrieval alone cannot
supply the missing inferential justification.

TCMScience addresses this boundary through a governed execution
architecture
(Figure [1](#S1.F1 "Figure 1 ‣ 1 Introduction ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine")).
The language model proposes a scientific program; a compiler checks its
types, effects, and evidence requirements; a trusted kernel authorizes
execution; and the release path verifies the resulting claims. Domain
knowledge enters through typed entities and contracts, including
medicinal identity, processing state, formula composition, exposure, and
source independence. These checks make TCM-specific scientific errors
inspectable and actionable within the same runtime that executes the
analysis.

The report makes three contributions. First, it specifies the separation
of generative reasoning, computational authority, and scientific release
as explicit architectural interfaces. Second, it formalizes evidence
support using typed claim obligations and provenance-bearing inference
paths, distinguishing serial dependencies from alternative support and
contextual citations. Third, it demonstrates the consequences of these
controls through a source-backed network-pharmacology analysis and a
layer-wise and gate-wise regression ablation. The emphasis is on the
scientific decisions changed by the architecture.

## 2 Related Work and Technical Positioning

### 2.1 Domain models, knowledge graphs, and retrieval

TCM diagnostic models focus on prediction from clinical or sensory
inputs\[[1](#bib.bib1)\]. Knowledge-graph systems address entity
integration and relational access\[[2](#bib.bib2)\], while TCM-focused
language models and GraphRAG systems improve domain interaction
\[[3](#bib.bib3), [4](#bib.bib4), [5](#bib.bib5)\]. TCM-QA further shows
the importance of evaluating knowledge across question formats and
languages\[[16](#bib.bib16)\]. TCMScience uses these capabilities within
a different control abstraction: a retrieved passage, a model-generated
interpretation, and a releasable claim have separate types and
validation states. The runtime preserves that distinction through
execution and bilingual presentation.

### 2.2 Scientific agents and executable research

Tool-using scientific agents demonstrate that language models can
coordinate chemistry, biomedical analysis, and hypothesis
generation\[[6](#bib.bib6), [7](#bib.bib7), [8](#bib.bib8),
[9](#bib.bib9), [10](#bib.bib10)\]. TCMScience treats the model and
connected tools as replaceable components behind governed interfaces.
Its contribution is the integration of authorization, scientific type
checking, source-state verification, and domain-specific claim
validation. This positioning is architectural: the experiments below
isolate governance effects on a fixed corpus and analysis choices in a
fixed case study, rather than rank foundation models or general-purpose
agents.

### 2.3 Provenance and valid biological interpretation

Provenance supports inspection of how data and analyses produce an
artifact, consistent with FAIR principles\[[17](#bib.bib17)\]. Resources
such as LOTUS, UniProt, STRING, Reactome, and Open Targets provide
complementary biological representations\[[18](#bib.bib18),
[19](#bib.bib19), [20](#bib.bib20), [21](#bib.bib21),
[22](#bib.bib22)\]. Their relations have different meanings: occurrence,
identifier equivalence, protein association, pathway membership, and
target–disease association are not interchangeable. TCMScience therefore
preserves relation semantics alongside source identity. Statistical
controls operate on this typed representation so that a change in
background population or evidence definition remains visible in the
resulting conclusion.

## 3 System Architecture

### 3.1 Components and interfaces

Figure [2](#S3.F2 "Figure 2 ‣ 3.1 Components and interfaces ‣ 3 System Architecture ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine")
details the components and data flow. TCMScience comprises three
coordinated planes. The _scientist plane_ maintains the research
question, hypotheses, protocols, predictions, observations, and
deviations. The _capability plane_, implemented in BioScience-Harness,
supplies connectors, native tools, parsers, datasets, and domain
workflows. The _governance plane_ maintains policies, skill manifests,
version locks, contracts, and validators. The Physician-Scientist
Harness (PSH-Harness) supplies the trusted kernel through which governed
execution and release pass.

TCMScience Studio provides the interactive interface; Python and
command-line entry points provide programmatic access to the same
research components. The implementation namespace bioagent belongs to
BioScience-Harness, psh to PSH-Harness, and tcmstudio to the Studio
local Runner. These names identify software components within one
architecture. Interactive exploration, scripted analysis, and batch
snapshot construction share the evidence and provenance model while
exposing the controls appropriate to each entry point.

### 3.2 Authority confinement and execution mediation

The kernel labels incoming data, freezes the applicable policy, and
binds the research task to an execution envelope. For an operation
$`o`$, let $`A_{\rm host}`$, $`A_{\rm project}`$, $`A_{\rm run}`$, and
$`A_{\rm skill}`$ denote the allowed actions at the corresponding
scopes. Its effective authority is

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
A_{\rm eff}=A_{\rm host}\cap A_{\rm project}\cap A_{\rm run}\cap A_{\rm skill},\qquad\mathrm{Authorize}(o)=\mathbb{I}[o\in A_{\rm eff}].
``` |  | (1) |

A skill whose declared requirements exceed this intersection is rejected
during validation. Delegation inherits an equal or narrower envelope,
and consumption is charged to the applicable budget scopes. Neither a
generated plan nor retrieved text can extend the authority in
Equation [1](#S3.E1 "In 3.2 Authority confinement and execution mediation ‣ 3 System Architecture ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine").

An execution broker mediates model, tool, and delegated calls. It
records requested actions, bindings, outcomes, and failure states. The
model gateway controls inference calls, the tool gateway controls
computation and external access, and the delegation gateway constrains
child workflows. Candidate outputs remain quarantined until validation.
Audit events form an append-only hash chain, and released artifacts
record the chain head used by the run. This provides tamper-evident
lineage within the trusted host and policy boundary; operating-system
isolation is a separate deployment property, not an implication of the
word “kernel”.

### 3.3 Scientific compilation

The scientific compiler transforms a proposed program into a typed,
bounded execution plan. The intermediate representation distinguishes
evidence, claims, operations, bindings, and effects. Evidence carries
study design, subject, population, intervention, comparator, outcome,
and provenance refinements. Claims specify the corresponding scope and
the kind of conclusion requested. Compilation checks graph structure,
type compatibility, permissions, data flow, statistical obligations,
reproducibility metadata, and resource limits before the program reaches
execution.

The compiler makes two separations explicit. Human-readable skill
descriptions explain a method, while machine-readable manifests define
its executable contract. Similarly, successful computation produces a
candidate artifact, while release requires a separate validation
verdict. Diagnostics identify the violated obligation and the
corresponding remedy, such as resolving a medicinal entity, supplying an
admissible source, or narrowing a claim. A repaired plan is revalidated
under the same authority ceiling.

### 3.4 Scientific state and governed skills

The scientist plane stores hypotheses and protocols as versioned
records, associates observations with the hypotheses they address, and
records deviations from planned analyses. The inquiry controller uses
predictions specified before execution to select informative analyses.
Its epistemic state remains separate from claim authorization: a high
posterior belief does not change the study design required to support a
conclusion.

Four core TCM skill contracts encode recurring domain obligations:
entity normalization, evidence retrieval, network-pharmacology analysis,
and safety-evidence assessment. They are composite workflows over the
capability registry, rather than a count of all available analytical
operations. Entity normalization exposes unresolved alternatives;
retrieval preserves evidence design and empty results; network
pharmacology separates measured activity from prediction; and safety
assessment distinguishes recorded risk, unmeasured outcomes, and absent
records. Skill promotion and version locking determine which
compositions enter the governed release path.

## 4 Evidence Semantics and Claim-Support Contracts

### 4.1 Evidence kinds and claim scope

A scientific claim is represented by its content, claim kind, subject,
population, intervention or exposure, comparator, outcome, direction,
and asserted certainty. An evidence record identifies the source and
locator, source version, study design, measured variables, and
verification state. A relation retains both *how the assertion was
generated* (for example, measurement, curation, prediction, or text
co-occurrence) and *the study design behind it*. These fields prevent a
curated prediction from being relabeled as an experiment merely because
it appears in a database.

Evidence kinds form a compatibility relation with claim kinds, rather
than a single ordered ladder. A randomized trial can support a bounded
human-outcome claim, but does not establish what an ancient text said.
Conversely, a classical passage can directly support textual attribution
while supplying no estimate of human efficacy.
Table [1](#S4.T1 "Table 1 ‣ 4.1 Evidence kinds and claim scope ‣ 4 Evidence Semantics and Claim-Support Contracts ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine")
summarizes the principal obligations. Source verification establishes
identity and integrity; it does not by itself establish adequate study
quality or inferential support.

|  Claim kind |  Relevant evidence |  Required boundary |
|----|----|----|
|  Textual attribution |  Located classical passage or source record |  Preserve wording, edition, locator, and attribution; do not infer a measured treatment effect. |
|  Traditional use |  Documented historical or practice source |  Retain the traditional indication, formula identity, preparation, and source context. |
|  Mechanistic hypothesis |  Docking, target prediction, network analysis, or exploratory preclinical evidence |  Label the conclusion as a hypothesis and preserve computational or experimental conditions. |
|  Experimental mechanism |  Relevant in-vitro or animal experiment |  Match biological system, intervention, concentration, outcome, and causal design; do not transfer directly to patients. |
|  Human association or effect |  Appropriately designed human study |  Match population, intervention, comparator, endpoint, and study design; retain uncertainty and bias assessment. |
|  Safety finding |  Explicitly measured and reported safety outcome |  Name the event, observation window, and population; an unmeasured outcome remains unknown. |

Table 1: Representative claim-support obligations. Permissions are
conditional on source verification and matching scope; evidence design
alone is not sufficient for release.

### 4.2 Formal release specification

Let $`c`$ be a candidate scientific claim, $`r`$ its run, and $`C(c)`$
the finite set of cited records. Citations have explicit roles:
supporting, contextual, or opposing. Let $`\mathcal{S}_{\pi}(c)`$ be the
family of candidate supporting subsets drawn from $`C(c)`$ under policy
$`\pi`$; every member is nonempty and contains only records offered as
support. Define $`V(e)`$ as successful verification of record identity,
integrity, and source binding; $`\mathrm{Suff}_{\pi}(S,c)`$ as
satisfaction of the complete claim-support contract by a supporting set
$`S`$; and $`G_{\pi}(r,c,C)`$ as successful execution, artifact, scope,
and whole-citation-set checks. A precise release condition is

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathrm{Release}_{\pi}(c,r)={}`$ | $`\displaystyle\mathbb{I}[C(c)\neq\varnothing]\left(\prod_{e\in C(c)}V(e)\right)\,G_{\pi}(r,c,C(c))`$ |  | (2) |
|  |  | $`\displaystyle}{\displaystyle\times\mathbb{I}\!\left[\exists S\in\mathcal{S}_{\pi}(c):\mathrm{Suff}_{\pi}(S,c)=1\right].`$ |  |  |

All factors in
Equation [2](#S4.E2 "In 4.2 Formal release specification ‣ 4 Evidence Semantics and Claim-Support Contracts ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine")
are Boolean. The explicit nonempty-citation condition and the
requirement for a nonempty sufficient supporting set make an
evidence-free claim fail even though an empty product equals one. If no
sufficient set exists, the existential condition is false. The gate also
requires the released wording to match the validated claim and records
unresolved conflicts and incomplete required assessments as failures of
the applicable contract. A cited opposing result cannot be ignored by
selecting a favorable subset.

The supporting set can contain one directly sufficient study or several
complementary records evaluated under a declared synthesis procedure.
Sufficiency requires claim-kind compatibility, matched scope, valid
inferential dependencies, and the quality and independence conditions
specified by the contract. It is not defined by taking the highest
evidence grade or by counting citations. In particular, a verified
randomized trial is not automatically sufficient for an unrestricted
efficacy statement.

### 4.3 Serial dependencies, parallel support, and context

The release contract distinguishes two forms of evidence composition. In
a serial derivation $`p`$, every indispensable edge must be valid and
must preserve its allowed claim type. In a set of alternative
derivations $`\mathcal{P}_{\pi}(c)`$, any complete sufficient derivation
can meet the support obligation:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathrm{PathValid}_{\pi}(p)`$ | $`\displaystyle=\bigwedge_{a\in p}\mathrm{Admissible}_{\pi}(a),`$ |  | (3) |
|  | $`\displaystyle\mathrm{Supported}_{\pi}(c)`$ | $`\displaystyle=\bigvee_{p\in\mathcal{P}_{\pi}(c)}\left[\mathrm{PathValid}_{\pi}(p)\wedge\mathrm{Sufficient}_{\pi}(p,c)\right].`$ |  |  |

The disjunction over no derivations in
Equation [3](#S4.E3 "In 4.3 Serial dependencies, parallel support, and context ‣ 4 Evidence Semantics and Claim-Support Contracts ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine")
is false. A branch requiring several complementary records uses
conjunctive obligations inside that branch; alternatives are disjunctive
only when each can independently satisfy the declared inference. The
“weakest link” principle therefore applies to indispensable
dependencies, not to every item in a bibliography.

For example, a properly scoped clinical-effect claim can be supported by
an admissible trial and accompanied by a docking study used only to
discuss a mechanistic hypothesis. The docking study is verified and
assessed against its own contextual role; it neither licenses the
clinical claim nor invalidates the trial’s support merely by being
cited. If the claim instead asserts that the predicted interaction
caused the clinical effect, the interaction becomes an indispensable
causal dependency and must satisfy that stronger obligation. Context
cannot serve as a route around the support contract.

### 4.4 Domain-specific overclaiming controls

TCM evidence requires constraints beyond generic citation matching.
Medicinal names retain botanical identity, plant part, processing state,
and aliases. Formula-level statements require formula-level support: a
result for one constituent cannot be transferred to a decoction by name
association alone. Processing changes are explicit, so evidence for a
processed medicinal is not silently reused for its raw counterpart.
Experimental concentration is retained when interpreting exposure, and
repeated access to the same study through multiple databases does not
create independent replication.

The output layer checks the natural-language statement as well as the
structured claim. It detects scope drift in subjects, populations,
outcomes, direction, and certainty; checks citation identity and quoted
passages; and rejects assertions about outcomes that the cited study did
not measure. Thus, the absence of an adverse-event entry is represented
as missing evidence, while an observed negative assay remains a measured
result under its assay conditions. This distinction is enforced in the
artifact, rather than delegated to cautionary wording in the final
response.

Registration, execution readiness, and scientific validation are
separate states. A call is admitted only when its operation, source
access, required dependencies, and policy conditions are satisfied. This
separation allows a large discovery catalog to coexist with narrowly
scoped execution contracts. Catalog growth cannot silently authorize
additional tools or change the evidence available to an ongoing
analysis.

Access modes include live API queries, downloaded snapshots, authorized
manual imports, and cataloged resources with restricted or unavailable
access. The analytic workflow parses raw records, normalizes typed nodes
and relations, applies quality checks, computes content hashes, and
registers the resulting snapshot in a ledger. Claims refer to
record-level identifiers and relations within that source state.
Snapshot loading rechecks content against the manifest and ledger; a
modified source state requires a new snapshot identity.

Source stewardship is part of the same contract. Cards retain
attribution, access conditions, and reuse permissions. A source’s
research availability and redistribution permission remain separate
fields. The snapshot pipeline records how an authorized source was
obtained, while the release artifact retains the lineage needed to
inspect and reproduce the derived result.

### 5.3 Identity resolution and reproducibility artifacts

Identifier alignment is an analytic operation. Compound records retain
source identifiers and standardized chemical cross-references; protein
mapping uses reviewed primary accessions; and formula relations preserve
source variants and medicinal roles. During development, auditing the
PubChem gene-to-UniProt crosswalk revealed mappings to secondary or
unreviewed accessions that did not align with the pathway reference.
Restricting mappings to unique reviewed human primary accessions
restored consistent cross-source joins. The case study in
Section [7](#S7 "7 Case Study: Evidence-Constrained Network Pharmacology ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine")
uses the corrected mapping.

A reproducible run binds the scientific program and skill version to
source snapshots, parameters, random seed, software identity, and output
digests. The network-pharmacology pipeline writes constituent, target,
enrichment, and network tables together with structured claims, release
decisions, and a provenance record. The provenance record includes
snapshot identifiers, source allowance, purpose, and ledger head. These
artifacts separate the observed data, the analysis applied to them, and
the claims permitted by that analysis.

## 6 Execution Lifecycle and Bilingual Research Interface

### 6.1 A common execution and release lifecycle

Figure [3](#S6.F3 "Figure 3 ‣ 6.3 Bilingual identity preservation ‣ 6 Execution Lifecycle and Bilingual Research Interface ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine")
presents the 16-stage lifecycle, from request ingestion to an audited
completion checkpoint. Policy binding precedes planning; plan validation
and capability resolution precede execution; and evidence ingestion,
verification, and release precede commitment of validated scientific
state. The same finalization boundary applies to a single tool workflow
and to a multi-step research loop.

Validation failures return typed diagnostics at the stage where they
occur. An unmet permission, unavailable capability, exhausted budget, or
invalid evidence path prevents release under the active contract. A
revised plan returns to validation, and subsequent iterations retain the
authority ceiling and audit lineage. Quarantine distinguishes
intermediate generated content from material authorized for scientific
reporting.

### 6.2 Independent model, compute, and network controls

Studio separates three configuration dimensions: the model endpoint used
for reasoning, the backend used for computation, and the hosts permitted
for external access. The default inference service is exposed under the
deployment alias Tao-S1. Compatible external or local model endpoints
can replace it without changing the scientific contracts. Model identity
and routing belong to run configuration, while claim authorization
remains a kernel function.

Lightweight Python computation runs in a browser Web Worker through
Pyodide/WebAssembly. The local Runner executes native Python workloads
and integrates installed computational engines for larger analyses.
Model calls and source queries retain their own network permissions even
when computation is local. This makes execution location and information
flow explicit architectural properties rather than assumptions inferred
from the user interface. Scientific capability is determined by the
selected backend, installed dependencies, and granted authority.

### 6.3 Bilingual identity preservation

Chinese and English interaction share canonical entities, source
locators, units, and claim types. Translation changes explanatory text
while retaining the identifiers that determine which evidence supports a
statement. Ambiguous names such as \zh姜 (jiang) require a distinction
between \zh生姜 (fresh ginger) and \zh干姜 (dried ginger), and formula
names retain their textual source or canonical record identifier.
Processing and near-name distinctions remain visible in both languages.

shows representative input-to-contract mappings. These are examples of
interface semantics, not additional empirical cases. The contract is

## 7 Case Study: Evidence-Constrained Network Pharmacology

### 7.1 Formula, records, and analytic specification

We analyzed Gegen Qinlian Tang (\zh葛根芩连汤), represented as the
four-herb formula comprising Puerariae Lobatae Radix (\zh葛根),
Scutellariae Radix (\zh黄芩), Coptidis Rhizoma (\zh黄连), and
Glycyrrhizae Radix et Rhizoma (\zh甘草). Composition records from NPASS,
CMAUP, and LOTUS yielded 1,792 formula-associated constituents. These
are source-linked constituents, not measured concentrations in an
administered preparation. Measured potency records covered 391 human
proteins, of which 237 had qualifying activity values at or below
$`10\,\mu\mathrm{M}`$. The hit definition used recorded IC₅₀, K_(i),
K_(d), or EC₅₀ values; a censored value that did not establish the
threshold was not treated as a qualifying hit.

Pathway analysis used Reactome membership, retained the declared
background population, and applied Benjamini–Hochberg (BH) correction
across all tested pathways\[[15](#bib.bib15)\]. Pathways were selected
using their original annotation size of 5–500 proteins; tests used
members falling within the specified background. An
annotation-degree-matched null further controlled the tendency of
extensively annotated proteins to contribute to many pathways. These
controls address distinct selection mechanisms and are retained in the
analysis specification.
Table [5](#S7.T5 "Table 5 ‣ 7.3 Inactive records recover a distinct screening signal ‣ 7 Case Study: Evidence-Constrained Network Pharmacology ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine")
summarizes the contrasts.

### 7.2 Assay coverage changes the pathway conclusion

With the full human Reactome annotation as background (12,155 proteins),
66 of 1,684 tested pathways passed the specified BH and
degree-matched-null criteria. Restricting the background to the 391
proteins actually assayed changed the test family to 959 pathways, none
of which passed the same decision procedure. The broad-background result
was therefore sensitive to assay coverage and did not support a
background-robust pathway claim.

The assay-matched result also identifies a concrete information
constraint: 237 of 391 assayed proteins were recorded as hits, a hit
fraction of 60.6%. Such a positive-enriched collection provides limited
contrast for overrepresentation. A nonsignificant result under this
background does not establish biological absence. The governed default
retains the analysis and its provenance while withholding a positive
pathway-mechanism claim. This is a scientific consequence of the
analysis specification, rather than a failure to produce a result.

### 7.3 Inactive records recover a distinct screening signal

The PubChem BioAssay analysis retained 143,679 explicitly classified
results across 1,029 human proteins: 10,696 active and 132,983 inactive
records. Under the default coverage threshold of at least 20 tested
constituents per protein, 472 proteins contributed 51,304
compound–protein tests, including 3,357 active results (6.54%). Analysis
at the test level preserves information that would be lost by labeling a
protein positive whenever any constituent was active.

The screening null sampled proteins together with their complete test
blocks to preserve within-protein dependence. Across 468 tested pathways
and 10,000 permutations, nine pathways passed the BH and permutation
criteria ($`q=0.008`$–0.026). Several involved cytochrome P450 and drug
metabolism. Five drug-metabolism pathways remained significant across
coverage thresholds of 10, 20, and 50 tested constituents. The released
interpretation is a screening-derived interaction hypothesis requiring
exposure and biological-context evaluation; it is not an observed
clinical interaction or a therapeutic-efficacy claim.

|  Analysis specification |  Result |  Permitted interpretation |
|----|----|----|
|  Potency hits; whole annotation background |  12,155 background proteins; 66/1,684 pathways significant |  Background-sensitive enrichment requiring assay-coverage control. |
|  Potency hits; assayed-protein background |  391 background proteins; 0/959 pathways significant |  No pathway passes the prespecified procedure; no positive mechanism claim released. |
|  Active/inactive screening; $`\geq 20`$ constituents per protein |  472 proteins; 51,304 tests; 9/468 pathways significant |  Screening-derived hypotheses, including drug-metabolism signals. |
|  T2DM genetic-association channel |  Overlap 9; fold 0.97; $`p=0.59`$ |  No detected enrichment under this disease-evidence definition. |
|  T2DM literature co-mention channel |  Overlap 57; fold 5.26; $`p=5.2\times 10^{-26}`$ |  Literature-defined overlap with potential shared-source and study-selection dependence. |

### 7.4 Disease evidence is a controlled analytic variable

For type 2 diabetes mellitus (T2DM; MONDO:0005148), Open Targets 26.09
supplied separate genetic-association and literature co-mention sets. At
a channel score threshold of $`0.5`$, the genetic set contained 478
proteins within the 12,155-protein Reactome background; nine overlapped
the 237 potency-qualified targets (fold enrichment 0.97; hypergeometric
$`p=0.59`$). The literature set contained 556 background proteins and
overlapped 57 targets (fold enrichment 5.26; $`p=5.2\times 10^{-26}`$).

These are different evidence-defined questions. Strong literature
overlap can reflect repeated study of familiar proteins and dependence
between text-mined associations and compound–target literature. It does
not substitute for independent genetic support. The background must also
remain attached to the statistic: with the 391-protein assayed
background, 14 proteins met the genetic criterion, the overlap remained
nine, and the corresponding result was fold 1.06 and $`p=0.50`$.
Reporting the background explicitly prevents these distinct calculations
from being mistaken for inconsistent estimates of one quantity.

The case demonstrates three architectural functions: source typing
determines what a target–disease edge means; the compiled analysis
records which population defines the statistical comparison; and release
preserves the distinction between an observed computational signal and a
biological or clinical conclusion. The system can therefore report an
informative negative analytic result and a separately supported
screening hypothesis without merging them into a single mechanism
narrative.

## 8 Governance Regression and Ablation

### 8.1 Corpus and evaluation design

We evaluated governance using scientific mutation testing. Ten compliant
base outputs (six Chinese and four English) were paired with structured
claims and source records. Mutation operators introduced one named
scientific error at a time, producing 121 erroneous outputs across 26
classes. Errors included population and endpoint substitution, altered
direction or certainty, predictions presented as clinical findings,
fabricated or tampered citations, near-name medicinal substitution, dose
errors, formula–constituent transfer, processing-state transfer,
unsupported human exposure, duplicate-study counting, and unmeasured
outcomes presented as negative findings.

The same artifacts were evaluated under no governance, domain-only
governance, kernel-only governance, and the full stack. The kernel
contributed evidence-ingest, output, and claim-kind licensing gates; the
domain layer contributed the TCM claim contract and snapshot-path
release check. Each gate was evaluated once per case, and configurations
were assembled from the enabled gate verdicts while preserving the
ingest-to-output dependency. This paired design isolates which checks
change release decisions; it does not measure model generation quality
or end-to-end discovery success.

## 9 Discussion

TCMScience makes scientific interpretation an executable obligation. The
model remains responsible for proposing useful analyses and
explanations, while source state, operation authority, and claim support
are evaluated by explicit runtime components. This separation reduces
dependence on a model’s willingness to follow a cautionary prompt and
makes a refusal traceable to a specific violated contract.

The case study and regression corpus support different conclusions. The
case study shows how background choice, inactive records, and
disease-evidence channels alter the permissible interpretation of one
formula analysis. The ablation shows complementary interception of known
constructed failure modes. Neither result establishes universal
hallucination prevention, clinical effectiveness, or superiority on
general biomedical task benchmarks. Independent research-task evaluation
is required to measure those broader properties.

The formal specification in Section 4 clarifies the intended distinction
between supporting, contextual, and opposing evidence and between
conjunctive dependencies and alternative support. The reported
regression counts evaluate the implemented gate configurations on their
fixed corpus; they are not additional validation of every
evidence-composition case in the specification. Source identity, study
quality, claim scope, and statistical validity remain separate
obligations, so a source hash or a high model confidence cannot
substitute for evidence that supports the conclusion.

The principal architectural advantage is therefore compositional
control: the same authority ceiling governs planning and execution, and
the same evidence contract governs structured claims and released
wording. This permits new models, tools, and datasets to extend the
scientific workspace while preserving an inspectable boundary around the
conclusions they can justify.

## 10 Conclusion

TCMScience is an autonomous scientific knowledge-discovery agent
dedicated to traditional Chinese medicine. Its trusted kernel,
scientific compiler, and claim-support contracts connect heterogeneous
research resources to a governed path from hypothesis to executable
analysis and evidence-bounded conclusion. The network-pharmacology case
demonstrates that source semantics and statistical controls change
scientific interpretation, while the regression ablation establishes
complementary error interception by the kernel and TCM domain layer on
the evaluated corpus. By separating generative reasoning from execution
and release authority, TCMScience provides a reproducible technical
foundation for scientific discovery across TCM and biomedicine.

## Appendix B Derivations for Authority and Claim Release

The following properties follow from the formal specification in the
main text. They concern the stated set and Boolean semantics; they do
not assert additional implementation coverage or introduce new empirical
validation.

### B.1 Authority contraction under additional restrictions

Index the four authority scopes by
$`i\in I=\{\mathrm{host},\mathrm{project},\mathrm{run},\mathrm{skill}\}`$.
Suppose a revised envelope satisfies $`A^{\prime}_{i}\subseteq A_{i}`$
at every scope. Then

|  |  |  |  |
|----|----|----|----|
|  |
``` math
A^{\prime}_{\rm eff}=\bigcap_{i\in I}A^{\prime}_{i}\subseteq\bigcap_{i\in I}A_{i}=A_{\rm eff}.
``` |  | (B.1) |

Indeed, an operation in every $`A^{\prime}_{i}`$ is in every
corresponding $`A_{i}`$. Consequently,
$`\mathbb{I}[o\in A^{\prime}_{\rm eff}]\leq\mathbb{I}[o\in A_{\rm eff}]`$.
For a child run, an inherited restriction
$`A_{\rm child}\subseteq A_{\rm parent}`$ preserves this inclusion at
each delegation step. Induction over the delegation chain therefore
bounds every descendant by the original envelope. This result requires
actual enforcement of the inherited sets; it is not an operating-system
isolation guarantee.

### B.2 Factorization of the release condition

For a fixed claim and run, abbreviate the three obligations as

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle E(c)`$ | $`\displaystyle=\mathbb{I}[C(c)\neq\varnothing]\prod_{e\in C(c)}V(e),`$ |  | (B.2) |
|  | $`\displaystyle W_{\pi}(c)`$ | $`\displaystyle=\mathbb{I}\!\left[\exists S\in\mathcal{S}_{\pi}(c):\mathrm{Suff}_{\pi}(S,c)=1\right],`$ |  |  |
|  | $`\displaystyle J_{\pi}(c,r)`$ | $`\displaystyle=G_{\pi}(r,c,C(c)).`$ |  |  |

Equation [2](#S4.E2 "In 4.2 Formal release specification ‣ 4 Evidence Semantics and Claim-Support Contracts ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine")
becomes

|     |                                                         |     |       |
|-----|---------------------------------------------------------|-----|-------|
|     |
       ``` math
       \mathrm{Release}_{\pi}(c,r)=E(c)W_{\pi}(c)J_{\pi}(c,r).
       ```                                                      |     | (B.3) |

Since each factor belongs to $`\{0,1\}`$, release equals one if and only
if all three factors equal one. In particular,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathrm{Release}_{\pi}(c,r)\leq E(c),\qquad\mathrm{Release}_{\pi}(c,r)\leq W_{\pi}(c),\qquad\mathrm{Release}_{\pi}(c,r)\leq J_{\pi}(c,r).
``` |  | (B.4) |

Verification alone is insufficient: $`E(c)=1`$ can coexist with
$`W_{\pi}(c)=0`$. A sufficient supporting set is also insufficient if a
required whole-set check fails, for example because an unresolved
opposing result affects the claim. When $`C(c)=\varnothing`$, $`E(c)=0`$
despite the empty product being one. When
$`\mathcal{S}_{\pi}(c)=\varnothing`$, $`W_{\pi}(c)=0`$ because the
existential statement has no witness.

### B.3 Serial obligations and alternative derivations

For a finite candidate family, Boolean conjunction and disjunction can
be written using products. Define

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle z_{p}`$ | $`\displaystyle=\mathrm{Sufficient}_{\pi}(p,c)\prod_{a\in p}\mathrm{Admissible}_{\pi}(a),`$ |  | (B.5) |
|  | $`\displaystyle\mathrm{Supported}_{\pi}(c)`$ | $`\displaystyle=1-\prod_{p\in\mathcal{P}_{\pi}(c)}(1-z_{p}).`$ |  |  |

The second line equals zero precisely when every $`z_{p}`$ is zero; it
equals one when any complete derivation succeeds. An indispensable
invalid dependency sets its own branch to zero. It does not set an
independent sufficient alternative to zero. For example, if a declared
inference requires both $`e_{1}`$ and $`e_{2}`$, while $`e_{3}`$ can
independently support the same scoped conclusion, the support structure
is $`(v_{1}\wedge v_{2})\vee v_{3}`$, where $`v_{i}`$ denotes the
applicable admissibility and support obligations, not merely source
verification.

A derivation with no dependencies cannot obtain support from an empty
product alone: it must still satisfy $`\mathrm{Sufficient}_{\pi}(p,c)`$
and the nonempty support requirement.
Equation [B.5](#A2.E5 "In B.3 Serial obligations and alternative derivations ‣ Appendix B Derivations for Authority and Claim Release ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine")
evaluates to zero when there are no candidate derivations. For set-based
and path-based descriptions to agree, each successful supporting set
must have a complete admissible inference witness, and each successful
witness must bind a permitted nonempty supporting set. This
correspondence is a requirement on their representation, not a
consequence of citation counts.

### B.4 Context, opposition, and changes to the citation set

Consider a verified clinical study used as support and a verified
docking record used as context. If the clinical study satisfies the
scoped support contract, the contextual record need not become an
indispensable clinical dependency. Both records still enter $`E(c)`$ and
the role-sensitive checks in $`J_{\pi}(c,r)`$. Changing the claim to a
causal assertion about the predicted interaction changes the support
obligations and requires revalidation.

Holding $`E`$ and $`J`$ fixed, adding an independently sufficient branch
cannot make $`W_{\pi}`$ decrease. Release, however, is not generally
monotone in the number of citations: adding an unverified record makes
$`E=0`$, and adding an unresolved contradictory result can make $`J=0`$.
Repeated database records of one study do not establish independence.
Identity deduplication and the synthesis contract must determine which
records can supply distinct evidential contributions.

## Appendix C Statistical Derivations for the Case Study

This section makes explicit the calculations underlying the reported
overlap comparisons and the distinction between background control,
multiple testing, and block-preserving screening analyses. Numerical
examples reuse the counts in
Section [7](#S7 "7 Case Study: Evidence-Constrained Network Pharmacology ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine").

### C.1 Hypergeometric overlap and fold enrichment

Let the fixed background $`U`$ contain $`N`$ proteins, with a set $`D`$
of $`K`$ proteins carrying the annotation or disease-evidence property
of interest. Under a null that selects $`n_{H}`$ proteins uniformly
without replacement, there are $`\binom{N}{n_{H}}`$ possible hit sets.
Exactly $`x`$ overlaps with $`D`$ can be formed by choosing $`x`$
proteins from $`D`$ and $`n_{H}-x`$ from its complement. Thus

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Pr(X=x)=\frac{\binom{K}{x}\binom{N-K}{n_{H}-x}}{\binom{N}{n_{H}}},\quad\max(0,n_{H}+K-N)\leq x\leq\min(n_{H},K).
``` |  | (C.1) |

The one-sided overrepresentation probability for observed overlap $`k`$
and the fold enrichment are

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle p_{\rm HG}`$ | $`\displaystyle=\Pr(X\geq k)=\sum_{x=k}^{\min(n_{H},K)}\frac{\binom{K}{x}\binom{N-K}{n_{H}-x}}{\binom{N}{n_{H}}},`$ |  | (C.2) |
|  | $`\displaystyle\mathbb{E}[X]`$ | $`\displaystyle=\frac{n_{H}K}{N},\qquad F=\frac{k}{\mathbb{E}[X]}=\frac{k/n_{H}}{K/N}.`$ |  |  |

The expectation follows by summing inclusion indicators, each with
marginal probability $`n_{H}/N`$, over the $`K`$ annotated proteins. The
fold is defined when $`n_{H}K>0`$. Degenerate sets must be handled
explicitly rather than assigned a finite fold by division by zero.

Table [C1](#A3.T1 "Table C1 ‣ C.1 Hypergeometric overlap and fold enrichment ‣ Appendix C Statistical Derivations for the Case Study ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine")
reproduces the disease-channel comparisons from the reported integers.
The genetic comparison changes from $`9/(237\times 478/12{,}155)=0.97`$
to $`9/(237\times 14/391)=1.06`$ when the universe changes. The same
overlap count therefore need not imply the same enrichment.

### C.2 Benjamini–Hochberg adjustment

For a declared family of $`m`$ tests, order the raw probabilities as
$`p_{(1)}\leq\cdots\leq p_{(m)}`$. The BH adjusted values are

|  |  |  |  |
|----|----|----|----|
|  |
``` math
q_{(i)}=\min\!\left\{1,\min_{j=i,\ldots,m}\frac{m}{j}p_{(j)}\right\}.
``` |  | (C.3) |

At threshold $`\tau`$, the step-up procedure finds
$`i^{*}=\max\{i:p_{(i)}\leq i\tau/m\}`$ and rejects the first $`i^{*}`$
hypotheses; if the set is empty, it rejects none. The reverse cumulative
minimum in
Equation [C.3](#A3.E3 "In C.2 Benjamini–Hochberg adjustment ‣ Appendix C Statistical Derivations for the Case Study ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine")
gives the same decisions through $`q_{(i)}\leq\tau`$. The test family
must be specified before selecting discoveries. Removing nonsignificant
pathways before adjustment would change the procedure. The original BH
guarantee assumes independent test statistics\[[15](#bib.bib15)\];
overlapping pathways and assay selection require explicit attention to
the null model and dependence structure. Adjustment alone does not
remove those sources of bias.

### C.3 Why active and inactive tests must remain together

For protein $`j`$, let $`t_{j}`$ be its number of classified tests and
$`a_{j}`$ the active count. For a selected protein set $`P`$, its
test-level active fraction is

|     |                                                               |     |       |
|-----|---------------------------------------------------------------|-----|-------|
|     |
       ``` math
       \widehat{f}(P)=\frac{\sum_{j\in P}a_{j}}{\sum_{j\in P}t_{j}}.
       ```                                                            |     | (C.4) |

This descriptive fraction differs from both the unweighted average of
$`a_{j}/t_{j}`$ and the fraction of proteins with at least one active
result. At the coverage threshold of 20 constituents, the reported
totals give $`3{,}357/51{,}304=6.54\%`$. Collapsing each protein to
$`\mathbb{I}[a_{j}>0]`$ would discard inactive outcomes and the unequal
numbers of tested constituents.

The reported screening null samples proteins with their complete test
blocks. In a general block-permutation formulation, a declared statistic
$`T`$ is computed for the observed pathway and for $`R`$ admissible
random draws. Blocks preserve within-protein dependence; eligibility,
pathway size, and any required matching constraints belong to the
sampling rule. For a random-draw upper-tail test that includes ties, a
standard finite-simulation estimate is\[[23](#bib.bib23)\]

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\widehat{p}_{\rm perm}=\frac{1+\sum_{b=1}^{R}\mathbb{I}[T^{(b)}\geq T^{\rm obs}]}{R+1}.
``` |  | (C.5) |

For $`R=10{,}000`$, this convention has minimum probability
$`1/10{,}001`$.
Equation [C.5](#A3.E5 "In C.3 Why active and inactive tests must remain together ‣ Appendix C Statistical Derivations for the Case Study ‣ TCMScience: An Autonomous Scientist for Traditional Chinese Medicine")
states a reproducible random-permutation convention, not a
reconstruction of unprovided draws. Recovering the reported nine
discoveries additionally requires the original statistic, admissible
sampling rule, random seed, pathway membership, and joint BH/permutation
criterion. Aggregate counts alone do not determine those results.

## Appendix D Exact Binomial Intervals and Their Interpretation

Under a binomial reference model, let
$`X\sim\mathrm{Binomial}(n,\theta)`$ and observe $`X=x`$. A two-sided
Clopper–Pearson interval\[[24](#bib.bib24)\] inverts the binomial tails:
for interior counts, its endpoints satisfy

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\Pr_{\theta=L_{x,n}}(X\geq x)=\frac{\alpha}{2},\qquad\Pr_{\theta=U_{x,n}}(X\leq x)=\frac{\alpha}{2}.
``` |  | (D.1) |

Using the binomial-tail identities with Beta distributions yields

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle L_{x,n}`$ | $`\displaystyle=\begin{cases}0,&x=0,\\
Q_{\alpha/2}(x,n-x+1),&x>0,\end{cases}`$ |  | (D.2) |
|  | $`\displaystyle U_{x,n}`$ | $`\displaystyle=\begin{cases}1,&x=n,\\
Q_{1-\alpha/2}(x+1,n-x),&x<n.\end{cases}`$ |  |  |

At zero observed events, $`\Pr_{\theta}(X=0)=(1-\theta)^{n}`$. Solving
$`(1-U_{0,n})^{n}=\alpha/2`$ gives the main-text expression

|     |                                                |     |       |
|-----|------------------------------------------------|-----|-------|
|     |
       ``` math
       U_{0,n}=1-\left(\frac{\alpha}{2}\right)^{1/n}.
       ```                                             |     | (D.3) |

For $`x=n`$, the symmetric boundary is $`L_{n,n}=(\alpha/2)^{1/n}`$. At
$`\alpha=0.05`$, the zero-event upper bounds are $`3.0027\%`$ for
$`n=121`$ and $`30.8497\%`$ for $`n=10`$, which round to the displayed
$`3.00\%`$ and $`30.85\%`$. These are two-sided 95% endpoints; replacing
$`\alpha/2`$ by $`\alpha`$ would instead compute a one-sided 95% upper
bound.

distinct purpose.
````
